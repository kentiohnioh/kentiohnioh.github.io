## 4. Runtime Memory & GPU Resource Management

1. **Monotonic LRU Texture Cache** (`TextureCache`):
   - Capped at maximum 24 active WebGL2 textures in VRAM.
   - Automatically unbinds and deletes oldest textures when threshold is exceeded.
2. **WebGL2 Context Loss & Recovery**:
   - Listens for `webglcontextlost` and `webglcontextrestored`.
   - Cleans up shader programs and reinstantiates pipelines cleanly on context restoration.
3. **Canvas Readback Throttling**:
   - Histogram and composition pixel readbacks are throttled at maximum 10 Hz (never executed on every animation frame).
4. **Dynamic Quality Governor**:
   - Continuously monitors frame execution time.
   - If 30 consecutive frames exceed 20 ms (falling below 50 FPS), visual effects degrade gracefully from `full` $\to$ `reduced` $\to$ `minimal`.
